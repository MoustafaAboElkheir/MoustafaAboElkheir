### 🛰️ Explainable Keyframe Selection for 360° 3D Reconstruction — *MSc research with BT*
Supervised by **Professor Hani Hagras**. An explainable, pose-aware system that selects a minimal set of keyframes from a 360° video walkthrough for efficient 3D reconstruction and object detection. A **15-rule zero-order Sugeno fuzzy selector** (behind a crisp quality gate) decides which frame to keep, orchestrated by a **LangGraph** agent; every decision writes an exact, replayable trace with no LLM. Reconstruction with **COLMAP + 3D Gaussian Splatting**, object detection with **YOLO**, evaluation with PSNR/SSIM/LPIPS, delivered with a local **FastAPI + React** demo. *🔒 Private (industry project).*

### 🤖 Agentic Data Scientist

### 🫀 ECG Signal Synthesis with GANs

### ⚡ Distributed K-Means (Spark &amp; Hadoop)
